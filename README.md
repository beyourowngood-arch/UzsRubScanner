# UZS → RUB Scanner

Одноэкранное Android-приложение для быстрого пересчёта цены из узбекских сумов в рубли.

1. Нажмите **Камера** или **Фото**.
2. Проведите пальцем по области снимка, в которой находится цена.
3. Нажмите **Распознать цену**.
4. При необходимости откройте **Курсы** и задайте прямой курс UZS/RUB или значения для
   пересчёта через USD. Настройки сохраняются на устройстве.

Приложение распознаёт цифры локально с помощью ML Kit и показывает исходную сумму, а также
результаты расчётов по настраиваемому прямому и кросс-курсу. Кнопки выбора снимка остаются доступны,
поэтому после результата можно сразу перейти к следующему фото.

## Сборка

```bash
gradle assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Workflow GitHub Actions выполняет
ту же сборку и загружает APK как artifact `app-debug.apk`.
